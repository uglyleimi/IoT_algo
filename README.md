## Варіант 3
Створити функцію на мові програмування Python, яка приймає дві стрічки:
"haystack" (довільний текст) та "needle" (шукана стрічка). Програма повинна
знайти кінцевий індекс останнього входження стрічки "needle" в стрічці
"haystack" та повернути цей індекс та кількість порівнянь символів, яку виконала
ваша функція, використовуючи naive-метод (метод повного перебору) пошуку
підстрічки у стрічці
